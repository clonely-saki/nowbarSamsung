# Project Instructions

- This project is a Samsung Galaxy Now Bar sports app.
- Primary goal: provide live sports and esports information through official Android Live Updates / promoted ongoing notifications.
- Current priority: verify compatibility with a real China-market Samsung Galaxy device before building production features.
- Sports includes both traditional sports and esports, especially football, basketball and League of Legends.
- Use Kotlin + Jetpack Compose.
- Prefer official Android APIs.
- Keep the architecture simple.
- Do not use AccessibilityService, root, Shizuku, hidden Samsung APIs, or system hacks unless I explicitly request them later.
- Do not add a backend yet.
- Do not connect real sports APIs yet.
- Do not redesign the app or add unrelated features.
- Do not refactor unrelated working code.
- Do not add dependencies unless they are actually necessary.
- Keep token/context usage efficient: inspect only files relevant to the current task instead of repeatedly scanning the entire repository.
- For implementation tasks, run the relevant build/tests before finishing whenever possible.
- Real Samsung device behavior is the final source of truth for Now Bar compatibility.
